## ✨ Features
- 💬 Real-time AI chat powered by Nvidia Nemotron
- 🎨 Apple Liquid Glass UI design
- 🌌 4 themes — Aurora, Sunset, Arctic, Obsidian
- 🖱️ Draggable floating theme switcher
- ✦ AI Prompt generator
- 📱 Fully mobile responsive

## 🛠️ Tech Stack
- **Frontend**: Vanilla HTML, CSS, JavaScript
- **Backend**: Node.js + Express
- **AI Model**: nvidia/nemotron-3-nano-30b-a3b
- **Server**: VPS + Nginx + PM2
- **SSL**: Let's Encrypt
